# tellurion-referee

A referee that detects when a learned world model disagrees with reality, and says why:
the **model** is wrong, the **sensor** is wrong, or **something new** is happening.
Built for the OSI hackathon (Oct 21–22, 2026) on a simulated pendulum with labelled ground truth.

> Work in progress. Results, figures and the demo link will appear here.

## Quick start
```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu   # optional: smaller CPU-only torch
pip install -e '.[dev]'              # core + tests (Python 3.11+)
# pip install -e '.[dev,eval]'      # also scikit-learn, matplotlib for metrics and figures
make test
```

## Repo layout
```
tellurion_sim/   reality engine: pendulum simulator + perturbations + dataset
src/referee/     world model, referee, baselines, evaluation
scripts/         train / evaluate / figures entry points
configs/         experiment configs
demo/            web demo (replays result files)
docs/plans/      build plans
results/ figures/  generated by scripts only
```
