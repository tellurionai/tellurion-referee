- **Detection is the headline.** The referee's detection score is the prediction gap, so it matches the simple gap alarm (B2, AUROC 0.982). Its added value is naming the cause.
- **Naming the cause is weak for sensor faults and new forces.** Main reason found: the referee names the cause at its first alarm, when its window is still mostly from before the fault. Next step: let it judge a few steps later.
- **'Caught when confidently wrong'** is defined by low ensemble spread, so the AI's own confidence scores 0% on it by construction. Use the missed-problems comparison as the fair headline.
- False-alarm rates were tuned to ≤ 5% on the calibration set; on the locked test they land slightly differently (reported as measured).
- Everything is simulated (a single pendulum) so that every run has a known answer. Real systems are next.
